Construction of the Polynomial Ring

A guided recap: each definition is followed by what it means in plain words and a worked example. The chapter builds from groups to rings to ideals to quotients, so that polynomials can be defined as a ring.

I. Groups

Definition 1: Group

A set G with an operation x ∗ y that stays inside G, such that:

  • Associativity: x ∗ (y ∗ z) = (x ∗ y) ∗ z
  • Neutral element e: x ∗ e = e ∗ x = x for every x
  • Inverses: every x has an x⁻¹ with x ∗ x⁻¹ = x⁻¹ ∗ x = e

If also x ∗ y = y ∗ x for all x, y, the group is commutative (abelian).

In words: a group is a set where you can combine things, undo any combination, and there is a "do nothing" element. Order of grouping never matters; order of elements may matter unless the group is abelian.

Examples
  • (ℤ, +) is abelian: neutral element 0, inverse of x is −x.
  • Any vector space under its addition is a group.
  • GLn, the invertible n×n matrices under multiplication, is a group (not abelian for n ≥ 2, since AB ≠ BA in general).
Definition 2: Subgroup

A non-empty subset H ⊂ G is a subgroup if the operation of G, restricted to H, makes H a group.

Two points to understand. Non-empty: H ≠ ∅. Restriction: for x, y ∈ H we need x ∗ y ∈ H (closure). Associativity is inherited from G; you only need to check the neutral element and inverses stay in H.

Example: 2ℤ ⊂ ℤ

Take x = 2k, y = 2m. Then x + y = 2(k+m) ∈ 2ℤ. Also 0 = 2·0 ∈ 2ℤ and −x = 2(−k) ∈ 2ℤ. So 2ℤ is a subgroup of ℤ.

Proposition: one-step test

H is a subgroup of G ⟺ H ≠ ∅ and for all x, y ∈ H: x ∗ y⁻¹ ∈ H.

This replaces three checks with one. In (ℤ, +) the "inverse of y" is −y, so the test reads x − y ∈ H.

Example: 2ℤ again

0 ∈ 2ℤ so it is non-empty. For x = 2k, y = 2m: x − y = 2(k−m) ∈ 2ℤ. Done in two lines.

II. Rings

Definition 1: Ring

A set A with two operations + and ∗ such that (A, +) is an abelian group (neutral element 0), ∗ is associative, and ∗ distributes over +.

A ring is a place where you can add, subtract and multiply, but not necessarily divide. Extra properties give extra names:

Unitary∃ 1A for ∗multiplication has an identity

The invertible elements (units) of A are written A× or U(A).

Definition 3: Subring

A subset B ⊂ A that is itself a ring with the same + and ∗.

Examples
  • ℤ: commutative, unitary, integral domain, not a field (2 has no inverse in ℤ). Units: ℤ× = {−1, 1}.
  • 2ℤ: commutative but no 1 (1 is odd), so not unitary and not a field.
  • Mn(ℝ): has zero-divisors (e.g. two non-zero matrices whose product is 0) and is not commutative, so neither integral domain nor field.
  • ℝ and ℂ are fields.
  • Gaussian integers ℤ[i] = {a + ib | a, b ∈ ℤ} are a subring of ℂ: sums and products of such numbers keep integer real and imaginary parts, since i² = −1.

Ring homomorphisms

Definition

A map φ: A → B with φ(x+y) = φ(x)+φ(y) and φ(x∗y) = φ(x)∗φ(y). It follows that φ(0A) = 0B and φ(−x) = −φ(x). For unitary rings one also requires φ(1A) = 1B.

A morphism is a map that respects both operations: computing before or after applying φ gives the same result.

Examples
  • Identity IdA(x) = x: trivially preserves sums and products.
  • Complex conjugation z ↦ z̄ on ℂ: (x+y)‾ = x̄ + ȳ and (xy)‾ = x̄ ȳ, and it fixes 0 and 1.
  • Evaluation Ex₀(f) = f(x₀) on functions ℝ→ℝ: (f+g)(x₀) = f(x₀)+g(x₀) and the same for products, because functions are added and multiplied pointwise.

III. Ideals

Definition

Let A be a ring. A left ideal is an additive subgroup I with a∗x ∈ I for all a ∈ A, x ∈ I. A right ideal asks x∗a ∈ I. An ideal is both.

Idea: an ideal absorbs multiplication. Multiply anything in I by any element of the whole ring and you stay in I. This is stronger than a subring (which is only closed under products of its own elements).

Example 1: ideals of a field

{0} and A are always ideals. In a field they are the only ones: if I contains x ≠ 0, then x is invertible, so 1 = x⁻¹∗x ∈ I, and then every a = a∗1 ∈ I, so I = A.

Example 2: ideals of ℤ

Every nℤ is an ideal: for x = mn and any a ∈ ℤ, a∗x = (am)n ∈ nℤ. So 6ℤ is an ideal of ℤ.

Remember

An ideal need not be a subring: it does not have to contain 1 (indeed if it contains 1 it is the whole ring). Also, the intersection of any family of left (resp. right) ideals is again a left (resp. right) ideal.

Ideal generated by a set

For a non-empty B ⊂ A, the ideal generated by B, written (B), is the smallest ideal containing B.

Example: (4, 6) in ℤ

Elements are 4a + 6b = 2(2a + 3b). Since 2a+3b can be any integer, (4, 6) = 2ℤ = (2). Likewise 6a + 9b = 3(2a+3b) gives (6, 9) = 3ℤ = (3).

IV. Quotient rings

Take a ring A and an ideal I. Declare x ~ y when x − y ∈ I. This is reflexive (x−x = 0 ∈ I), symmetric, and transitive, so it is an equivalence relation. The class of x is written x̄.

Quotient ring A/I

The set of classes, with x̄ + ȳ = (x+y)‾ and x̄ ∗ ȳ = (x∗y)‾. These are well defined precisely because I is an ideal: changing representatives by an element of I does not change the result.

Example: ℤ/2ℤ and ℤ/6ℤ

"Same remainder on division by 6" is exactly x − y ∈ 6ℤ. The classes:

ClassElements
0̄…, −6, 0, 6, 12, …
1̄…, −5, 1, 7, 13, …
2̄…, −4, 2, 8, 14, …
3̄…, −3, 3, 9, 15, …
4̄…, −2, 4, 10, 16, …
5̄…, −1, 5, 11, 17, …

So ℤ/6ℤ = {0̄, 1̄, 2̄, 3̄, 4̄, 5̄}; similarly 0̄ = 2ℤ and ℤ/2ℤ = {0̄, 1̄} (evens and odds).

V. The polynomial ring

From here on, K is ℝ, ℚ or ℂ.

Definition: polynomial

A polynomial over K is a sequence P = (a₀, a₁, a₂, …) of elements of K in which only finitely many terms are non-zero (there is an N with an = 0 for all n > N). The set of all of them is K[X].

This is the "construction": a polynomial is defined as its list of coefficients, so (1, 2, 0, 3, 0, 0, …) is the object we usually write 1 + 2X + 3X³. The symbol X is just a placeholder for position.

  • The zero polynomial has all coefficients 0.
  • A constant polynomial is (a₀, 0, 0, …).
  • Equality: P = Q iff an = bn for every n.

1) Degree and valuation

Definitions

For P ≠ 0: deg(P) = max{ n | an ≠ 0 }. Conventions: deg(0) = −∞ and v(0) = +∞.

The constant term is a₀. The leading coefficient is ad with d = deg P. P is monic if that coefficient is 1. P is a monomial if v(P) = deg(P).

About v(P)

The valuation v(P) is the index of the first non-zero coefficient (the lowest power that appears). The notes use it without defining it. If v(P) = deg(P), the first and last non-zero terms coincide, so only one term exists: P = aXn.

Example

P = 3X² + X⁵: v(P) = 2, deg(P) = 5, leading coefficient 1, so P is monic but not a monomial. Q = 4X³ is a monomial (v = deg = 3).

2) Algebraic structure

P + Q = (an + bn)n P ∗ Q = (cn)n,   cn = Σi=0n ai bn−i = a₀bn + a₁bn−1 + … + anb₀

Addition is coefficient by coefficient. The product formula is the "expand and collect powers" rule: cn gathers every pair of terms whose exponents add up to n.

Example

(1 + X)(1 + X) has P = Q = (1, 1, 0, …). Then c₀ = 1, c₁ = a₀b₁ + a₁b₀ = 2, c₂ = a₁b₁ = 1, giving 1 + 2X + X².

Result: K[X] is a commutative unitary ring (the unit is (1, 0, 0, …)) with no zero-divisors, hence an integral domain. The reason: the leading coefficients multiply to a non-zero number, so deg(PQ) = deg P + deg Q for non-zero P, Q. It is not a field: X has no inverse, since the degree of a product of non-zero polynomials is never negative.

3) Polynomial function

Each P gives a function K → K, x ↦ P(x). Over ℝ, ℚ, ℂ (infinite fields), two polynomials with the same function are equal, but the polynomial itself is the coefficient sequence, not the function.

4) Euclidean division

Theorem

For A, B ∈ K[X] with B ≠ 0, there is a unique pair (Q, R) with

A = B·Q + R,   R = 0 or deg(R) < deg(B).

Q is the quotient and R the remainder. This mirrors integer division, with "degree" playing the role of "size". It is what makes K[X] behave like ℤ: every ideal is generated by a single polynomial, and quotients K[X]/(B) are built just like ℤ/nℤ.

Example

Divide A = X³ + 2X + 1 by B = X − 1. Subtracting X²·B leaves X² + 2X + 1; subtracting X·B leaves 3X + 1; subtracting 3·B leaves 4. So Q = X² + X + 3, R = 4, and indeed R = A(1) = 4.
